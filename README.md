## 📋 課程簡介

本課程為 **2 天制實體認證課程**，協助學員：

- 🧠 **建立 AI 素養** — 理解 AI 的核心概念與應用場景
- 📝 **掌握提示詞設計** — 有效運用 AI 工具輔助學習
- 📂 **整理學習成果** — 以 STAR-AI 框架記錄學習歷程
- 🎤 **通過認證考試** — 40 題題庫、隨機抽 20 題，80 分通過

## 🔐 帳號系統

```
登入角色
│
├─► 👤 管理員 (admin) ──► admin.html
│    └─ 新增/編輯/刪除帳號、設定師長歸屬
│
├─► 👨‍🏫 師長 (teacher) ──► teacher.html
│    └─ 查看班級學員 + 考試成績
│
└─► 🎓 學員 (student) ──► index.html
     └─ 瀏覽課程 + 填寫學習單 + 參加考試
```

> ⚠️ 所有資料儲存於瀏覽器 `localStorage`，無需伺服器

## 🚀 快速開始

```bash
# 直接在瀏覽器開啟即可使用，無需安裝

```

## 📊 認證考試規格

| 項目 | 規格 |
|:---|:---|
| 🗂️ 題庫總題數 | 40 題 |
| 📝 每次出題 | 隨機抽 20 題 |
| ⏱️ 考試時間 | 30 分鐘 |
| ✅ 通過門檻 | 80 分（16 題）|
| 💾 成績記錄 | 保留最高分 |

**考試範圍：** AI 基本概念、提示詞設計、學習歷程、面試技巧、AI 倫理
